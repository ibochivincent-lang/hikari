Hikari Developer SDK (@hikari/sdk)

Production-grade TypeScript SDK for interacting with Soroban liquid staking contracts, auto simulation, and passkey signers.

Terminal (Install)
npm install @hikari/sdk @stellar/stellar-sdk
quickstart.ts 
import { HikariSDK } from "@hikari/sdk";

// Initialize on Stellar Testnet
const hikari = new HikariSDK({ network: "testnet" });

// 1. Fetch live vault state & APY
const state = await hikari.getVaultState();
console.log(`NAV: ${state.navPerShare} XLM | APY: ${state.apy}%`);

// 2. Pre-flight simulation & deposit
const sim = await hikari.simulateStake({ amountXlm: 250 });
console.log(`Est. shares: ${sim.estShares} hXLM`);

// 3. Submit Passkey-signed transaction
const tx = await hikari.stake({ amountXlm: 250, signer: passkeySigner });
console.log(`Confirmed in ledger! Tx: ${tx.txHash}`);

Formal Invariant Specifications

Deterministic mathematical safety properties proven across 365-epoch Monte Carlo simulations and Soroban test suites.

INV-1: Share Pricing & Virtual Reserves
Shares = (Assets * (TotalShares + 1000)) / (TotalAssets + 1). Inflation attacks mathematically impossible.
INV-2: Monotonic NAV Growth (Non-Decreasing)
In normal cycles, NAV per share never decreases: d(NAV)/dt >= 0. Yield and MEV profits compound into share value.
INV-3: Bunker Mode & Drawdown Haircut
When drawdown > 15%, GateSeal locks allocations, switching to FIFO queue with pro-rata haircut preventing bank runs.
INV-4: Reserve Floor Conservation
At least 15% of total protocol capital remains liquid in the vault reserve buffer at all times for instant unstakes.

Hikari Protocol FAQ

What is hXLM?

hXLM is the SEP-41 compliant yield-bearing liquid staking token on Stellar. Holding hXLM continuously earns compounded yield from Blend lending, Phoenix CLAMM fees, and Jito MEV backruns.

How does unbonding work?

Under Turbo Mode, unstaking requests are settled immediately from the 15%+ liquid reserve buffer. If the queue is congested or market volatility spikes, requests are queued in FIFO order to protect the vault.

What is GateSeal and Dual Governance?

Adopted directly from Lido, GateSeal is a one-shot circuit breaker that pauses contract allocations for 7 days during critical anomalies. Dual Governance empowers stakers with veto rights against malicious DAO proposals.
